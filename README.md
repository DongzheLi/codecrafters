# CodeCrafters

Parent repository for CodeCrafters challenge work.

Challenges live as Git submodules grouped by implementation language:

```text
python/
go/
c/
cpp/
```

Add a new challenge from the repository root with:

```sh
git submodule add <codecrafters-repo-url> python/<challenge-name>
```

Use the matching language folder, for example `go/<challenge-name>` for Go.
